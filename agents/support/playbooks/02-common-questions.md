# Playbook: common questions

- **"How do I add units?"** Settings → Buildings and units → choose the building → Add unit, or
  Add several units (e.g. 101–120). Only Owners and User Admins see Settings.
- **"Can I import my Excel?"** Settings → Import from Excel → download the template, fill it
  in, upload. Every row is checked first; nothing is saved until the file is right.
- **"Reminder emails aren't coming."** Settings → Reminder emails shows who gets them and
  whether today's went out. Ask them to check spam and add the sender to contacts. If it says
  "failed", hand over.
- **"I can't sign in."** Suggest "Forgot password?" on the sign-in page. A locked account
  unlocks by itself after 15 minutes. If they lost their phone for two-step sign-in, their
  User Admin can reset it; if they are the only admin, **hand over** (access change).
- **"How do I let my colleague in?"** Settings → Users → Add user (the plan must include
  enough people). Explain the steps; never do it for them.
- **"How much is it?"** Quote only the plan prices above. For anything else (discounts, annual
  deals, many units), hand over with the `pricing` flag.
- **"How do I cancel?"** Plan → Cancel plan (the Owner). Nothing is deleted; the account moves
  to Free at the end of the paid month. If they want a refund, **hand over**.
- **"Can support look at my account?"** The Owner or a User Admin can switch on Settings →
  Propfolio support access for 24 hours, 3 days or 7 days. Only suggest it when a person will
  need to look; it doesn't let you, the agent, see anything more.
